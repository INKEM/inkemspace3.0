# 迁移强化学习系列到知识库

## 数据现状

- 4 个系列目录(目录名含「强化学习」):强化学习基础(8 篇)、深度强化学习(7 篇)、分层强化学习(7 篇)、基于模型的强化学习(4 篇),共 24 篇
- 标题格式统一:`【系列名】#序号 主题(：副标题)`;24 篇全部含 KaTeX 数学公式,17 篇图片(全为 COS 外链,无需搬资源),无 mermaid、无 `:::` 指令
- 「模仿学习」目录不含「强化学习」字样,不属于本次范围(需要的话之后可同样方式加入)

## 1. 目录结构(二级分类 + `_category_.json`)

```
knowledge/docs/
├── intro.mdx(现有简介,保持 sidebar_position 0)
└── 强化学习/
    ├── _category_.json            # label: 强化学习, position: 1, generated-index
    ├── 强化学习基础/_category_.json  # position 1(教学顺序:基础→深度→基于模型→分层)
    ├── 深度强化学习/_category_.json  # position 2
    ├── 基于模型的强化学习/_category_.json # position 3
    └── 分层强化学习/_category_.json  # position 4
```

文章文件保留原文件名放入对应系列目录(便于日后与博客对照)。

## 2. 文章 frontmatter 转换(脚本迁移,一次脚本放 /tmp 不进仓库)

例:`【深度强化学习】#1 DQN：深度Q学习` →

```yaml
---
format: md
title: DQN：深度Q学习 # 省略系列名【…】和序号 #N
sidebar_label: DQN # 冒号前部分;无冒号则完整标题(如「策略梯度定理」「引论」)
sidebar_position: 1 # 用原 #N 保持系列内阅读顺序(避免按字母乱序)
description: <原 summary 字段>
tags: <原 tags 原样保留>
custom_edit_url: false # 笔记源头在博客,关闭"编辑此页"
---
<正文原样拷贝>
```

- `format: md` 让这些纯笔记按普通 Markdown 解析,规避 MDX 对正文里 `{`、`<` 的严格校验(博客笔记按纯 Markdown 书写)

## 3. 数学公式支持(必需新增)

- knowledge 内 `npm install remark-math rehype-katex`(与博客同款渲染栈)
- `docusaurus.config.ts` 的 docs 配置挂载 `remarkPlugins: [remarkMath]`、`rehypePlugins: [rehypeKatex]`
- `custom.css` 顶部 `@import 'katex/dist/katex.min.css'`(字体随包打包,离线可用)

## 4. 验证

- 构建 knowledge,如有报错逐个修复;成功后 copy 到 dist
- 浏览器实测:侧边栏结构(强化学习 ▸ 四个系列 ▸ 短索引文章列表、顺序正确)、打开含公式和图片的文章(如 DQN)确认渲染
- 完整 `pnpm build` 流水线跑通

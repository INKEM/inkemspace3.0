## 如何新增笔记

在 `docs/` 下按分类建立文件夹，每篇笔记一个 Markdown 文件，分类信息通过 `_category_.json` 配置，侧边栏会自动生成：

```json
{
  "label": "ROS 2",
  "position": 1,
  "link": {
    "type": "generated-index",
    "description": "ROS 2 学习笔记"
  }
}
```
